Añadir tarjeta

Importa un archivo HTML autónomo. Se guardará en este dispositivo y aparecerá en el carrusel principal. Si utiliza imágenes o archivos externos, deben estar integrados en el propio HTML o disponibles mediante una dirección web.

Seguridad: importa únicamente archivos HTML de confianza. Las tarjetas se abren en un espacio aislado. Para guardar datos propios, utiliza la API window.ADMelioraStorage; el acceso directo a localStorage, sessionStorage, IndexedDB y cookies no está disponible en ese espacio.

Guardado compatible
Ejemplo: await ADMelioraStorage.setItem('preferencias', JSON.stringify(datos))
Para leer: const texto = await ADMelioraStorage.getItem('preferencias')
También dispone de removeItem(clave), keys() y clear(). Los datos se guardan por tarjeta y se incluyen en la copia integral de AD MELIORA.
